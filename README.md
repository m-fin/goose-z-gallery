# Goose Z

A private iPhone companion for *Goose Z*, Matthew Finley’s coffee-table book. Ivory and gold, full-bleed plates, short italic captions.

Bundle id: `app.goosez.gallery`.

## Run

```bash
npm install
npx expo start
```

Type-check with `npm run typecheck`. Export the bundle with `npx expo export`.

## What’s inside

- A swipeable gallery of the original plates, with pinch and double-tap zoom
- A V-launch sequence: the skein eases across the sky while the book’s plates change under it
- Favorites, kept on the phone
- Goose of the day, and an optional morning notice at 7:30
- A listing control for the hardcover. The Amazon page is not live; the URL stays empty until it is
